# 使用指南

先完成 [README 中的安装步骤](../README.md#快速安装)，再在支持该技能的对话中调用 `$douyin-house-tour`。下面的房源信息均为虚构练习；实际使用时换成已经核实的资料。

## 1. 写完整口播

```text
使用 $douyin-house-tour，写一版约 30 秒的卖房口播，只给正文。

房源：建筑面积 86 平方米，两居，报价 98 万元。
厨房有门；客厅摆着四人餐桌；两间卧室各有柜子。
餐桌和两间卧室的柜子明确随房交付。
面向家庭买家，语气亲近、利落。
未知朝向、柜体容量和周边配套，不要补充。
```

资料越具体，越容易写出属于这套房的角度。面积不够推断居住人数，已知报价也不等于有依据称其便宜。

## 2. 改写已有原稿

```text
使用 $douyin-house-tour，改写下面的口播，约 30 秒，只给成稿。

原稿：这套 148 平方米，四房两卫，有一个带门的独立书房，
客餐厅相连，喜欢读书的朋友可以来看看。

保留上述事实。别再逐项报配置，从“给爱好留一间房”展开，
语气有观点但自然，不承诺隔音，不虚构家庭成员。
```

可以明确需要保留的事实、账号用语或语气，也可以指出不喜欢的段落。技能会重做组织和表达，而不是只换同义词。

## 3. 同一房源写多个版本

```text
使用 $douyin-house-tour，为同一房源写两版约 30 秒口播。

建筑面积 86 平方米，两居，报价 98 万元。
厨房有门，客厅有四人餐桌，两间卧室各有柜子。
餐桌和柜子随房交付。

第一版围绕明确报价与交付条件，第二版从日常使用场景切入。
两版要改变主要出售理由和展开方式，不要只换开头。
不用分镜，也不要添加未知配置。
```

同样的事实可以反复使用，主要观点、叙述顺序或情绪推进要有实际变化。

## 4. 只要开场或局部片段

```text
使用 $douyin-house-tour，只给 3 个不同方向的短开场，不写整稿。

建筑面积 58 平方米，两居，厨房有门；
客厅现有一张可以展开、收起的折叠餐桌。
没有尺寸和展开后通行数据，不承诺不拥挤。
语气轻松、有记忆点。
```

如果只需要一句收尾、一个转场或一段金句，直接说明交付范围。不提供具体房源时，也可以要求不包含具体房源事实的通用创意方向。

## 5. 写家具或物件特写

```text
使用 $douyin-house-tour，只介绍这张餐桌，写约 15 秒口播。

已经确认：收起时 1.2 米，展开后 1.8 米，可以伸缩。
画面准备演示拉开和收起。
是否随房交付未知，不提赠送；不猜能坐多少人。
```

局部资料可以形成完整短片段，不需要补成一篇整屋介绍。

## 6. 使用照片或视频

在支持图片或视频读取的宿主中附上素材，再发送：

```text
使用 $douyin-house-tour，根据我附上的玄关和厨房素材，
写一版约 30 秒的看房解说，语气活泼。

已确认：建筑面积 118 平方米，三室两厅。
其他配置只采用素材里明确可见的内容。
不推断材质品牌、柜体容量、产权、隔音和通风性能。
如果有素材无法读取，先简短说明能用哪些资料。
```

素材读取能力由宿主提供。无法播放视频或访问图片时，可以改为提供截图、文字描述或转写；不能把无法读取的内容说成已经看过。

## 7. 参考博主或作品

发送实际作品链接、可读取文字或字幕，并说明想借鉴的方面：

```text
使用 $douyin-house-tour，参考我提供作品的开头节奏和信息释放方式，
不要复用其标志性口头禅、人物经历和房源条件。

我的房源：148 平方米，四房两卫，一间带门的独立书房，客餐厅相连。
写约 30 秒正文，另外给 3 条简短拍摄提示，放在正文之后。
参考无法访问时，说明读取范围，按已有资料完成。
```

仓库中的 [抖音观察记录](../douyin-house-tour/references/douyin-observations.md) 适合了解既有研究方法。需要最新热点时，应核实当前来源，不能把历史点赞和访问记录当成实时排名。

## 时长与输出

| 目标时长 | 一般字数 | 说明 |
| --- | --- | --- |
| 15 秒 | 约 50 至 70 个汉字 | 适合开场、局部或物件 |
| 30 秒 | 约 100 至 140 个汉字 | 适合围绕一个主要理由展开 |
| 60 秒 | 约 220 至 280 个汉字 | 默认完整口播长度 |

这是估算，拍摄演示和停顿较多时需要减少文字。默认交付连贯正文；需要标题、分镜、多版本、拍摄提示时一并说明。拍摄提示应与可朗读正文分开。

## 常见问题

### 安装后找不到技能

确认安装目录直接包含 `SKILL.md`，文件夹名是 `douyin-house-tour`，并且 `references/` 和 `agents/` 一起复制。新一轮对话中使用 `$douyin-house-tour`；仍未出现时重启 Codex。当前目录与安装位置的说明见 [官方文档](https://developers.openai.com/codex/skills/)。

### 没有价格、朝向等资料，还能写吗

可以。提供已知布局和几处真实细节，要求只围绕这些内容写。未知信息应省略，不需要为了凑齐模板而编造。

### 写出来太像其他房源怎么办

补充一两个这套房独有的关系，例如厨房与餐桌的位置、独立书房与客餐厅的分开方式、家具展开前后的变化；再要求更换主要出售理由。只说“更炸一点”通常不足以帮助模型找到新角度。

### 能直接剪视频或发布到抖音吗

本仓库提供写作技能，不包含剪辑、视频生成或发布程序。可以按需要求分镜和拍摄提示，后续制作与发布使用相应工具完成。

### 是否要调用额外 API 或安装开发环境

技能本身不需要。需要一个支持加载技能的 AI 宿主；图像理解、视频读取和联网能力以该宿主实际提供的功能为准。
